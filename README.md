# ARTI-404: Digital Image Processing
Welcome to my repository for the Digital Image Processing course. This repository contains laboratory exercises and projects implemented using Python, focusing on the fundamental principles of image representation, enhancement, and analysis.

## Course Overview
This course bridges the gap between theoretical image processing and practical applications. It covers the essential techniques that form the foundation for Computer Vision and Deep Learning.

## Key Topics
- Fundamentals: Image representation and mathematical foundations.
- Transformations: Intensity and color space transformations.
- Filtering: Spatial and frequency domain filtering (Smoothing & Sharpening).
- Morphological Operations: Dilation, erosion, opening, and closing.
- Feature Extraction: Edge detection, segmentation, and analysis pipelines.

## Tech Stack
The labs are implemented using the following tools:

- Python 3.x
- NumPy: For efficient matrix operations and image manipulation.
- OpenCV: For advanced computer vision tasks and image processing.
- Matplotlib: For data and image visualization.
- Jupyter Notebooks: For interactive coding and documentation.
